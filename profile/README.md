# CubixMC

Réseau Minecraft francophone : Rush, Hunger Games et un hub plein de mini-jeux.
**Jouer :** `mc.cubixmc.fr` · **Site :** [cubixmc.fr](https://cubixmc.fr)

## Développer pour CubixMC

Les serveurs tournent sur notre propre moteur, construit sur [Minestom](https://minestom.net).
Les jeux et fonctionnalités sont des **modules** écrits uniquement contre notre API publique :

- [`cubix-api`](https://github.com/CubixMCDev/cubix-api) : l'API (licence Apache 2.0), sa documentation et un exemple de module.
